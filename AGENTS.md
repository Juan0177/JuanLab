# Agent Instructions (JuanLab)

## Objective
Lavora in autonomia sul repository per completare il task richiesto, mantenendo modifiche sicure e minimali.

## Quality defaults
- Migliorare SEO/performance quando pertinente (meta, heading, alt, asset)
- Non introdurre regressioni visive evidenti
- Mantenere compatibilità con il comportamento attuale salvo richiesta diversa

## Workflow PR
- Apri sempre una PR per le modifiche.
- Se la PR è integrabile senza conflitti (merge pulito), esegui tu stesso il merge in `main`.
- Se ci sono conflitti o problemi di merge, risolvili prima di completare il merge.
